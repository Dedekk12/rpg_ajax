# rpg_ajax 

Um sistema em que você pode criar um personagem salvar seus dados e editar suas características e itens.

## Requisitos : 
### O Usuario pode
  - Ser capaz de realizar login
  - Criar 1 e apenas um personagem que está associado ao login
  - Armazenar dados de Ferramentas
  - Visualizar páginas apenas após o login ser efetuado

### O sistema deve contemplar os seguintes CRUD's
   - CRUD de Personagens
   - CRUD de Ferramentas
   - Um carrosel de card's na Home page (ajax aplicado)
   - Uma música de fundo interativa (opcional)
